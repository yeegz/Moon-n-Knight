# Moon n Knight

A Godot game project with GDScript gameplay code, level scenes and sprite assets. The repository records an earlier game-development project alongside my current mobile and web work.

## Open the project

1. Use Godot 4.3, the version recorded in `project.godot`.
2. Import `project.godot` from this repository.
3. Run the project in the editor. The configured starting scene is `level_1/scenes/node_2d.tscn`.

## Source layout

- `general_scripts/` — shared scripts, including the global autoload.
- `general_scenes/` — shared scenes.
- `level_1/` — the first level and its starting scene.
- `sprites/` — game artwork.

The project input map defines W, A, S and D for directional actions, with controller mappings alongside them.
